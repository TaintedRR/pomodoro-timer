# Pomodoro-таймер

Таймер по технике Pomodoro: 25 минут фокуса, короткий перерыв, а после четырёх циклов длинный.

**Демо:** https://taintedrr.github.io/pomodoro-timer/

## Возможности

- Режимы «Фокус», «Короткий перерыв» и «Длинный перерыв» со своим цветом.
- Кольцо прогресса на SVG и оставшееся время во вкладке браузера.
- Автоматический переход к следующему этапу (включается в настройках).
- Звуковой сигнал, сгенерированный через Web Audio API, без аудиофайлов.
- Поле «Над чем работаешь?» и журнал завершённых помидоров за день.
- Своя длительность каждого режима.
- Горячие клавиши: пробел запускает и ставит на паузу, R сбрасывает.
- Таймер считает время от отметки окончания и не отстаёт в фоновой вкладке.

## Технологии

HTML, CSS, JavaScript без библиотек: SVG `stroke-dashoffset`, Web Audio API, `localStorage`.

## Запуск

Открой `index.html` в браузере. Сборка не нужна.
